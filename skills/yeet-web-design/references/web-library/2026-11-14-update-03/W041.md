## Görsel gözlem

Açık mavi dış sunum zemininin içinde beyaz, yuvarlatılmış site çerçevesi var. Hero'da büyük koyu sans mesaj solda, beyaz kübik yapı sağda. Küçük kahverengi eylemler, alt solda hizmet etiketleri ve alt sağda iki küçük proje önizlemesi bulunuyor. Orta bölümde beş numaralı süreç satırı solda; ikinci satır açık kahverengiyle vurgulanmış. Sağda büyük proje fotoğrafı ve açıklama var. Alt koyu bölüm soldaki mesaj ve eylemi, sağdaki üç dikey proje kartıyla dengeliyor. Üstteki tasarımcı kullanıcı adı siteye ait değil.

## Prompt

```text
Design an architecture-studio website for [BRAND] and [AUDIENCE], using [VERIFIED_CONTENT], [APPROVED_ASSETS] and [PRIMARY_ACTION]. Adapt W041's link between a numbered project process and a corresponding explanatory image.

Use a clear light hero with a strong sans-serif message, a recognizable architectural scene and a restrained earthy action color. If project previews appear in the opening, identify them clearly and keep them from covering the main building. Introduce the working process as a concise ordered list beside one relevant image and explanation.

Decide explicitly whether process rows are navigation, tabs or a static sequence. If they change the adjacent content, define focus, selected state and keyboard behavior; the source only shows a highlighted row. Follow with a darker project section whose images, names and roles are readable and genuinely distinct. Avoid reusing the same scene as several supposed completed projects.

On narrow screens, pair each process explanation with its corresponding label and prevent service tags or previews from becoming unreadably dense. After plan approval, verify project links, the chosen process interaction and the contact flow. Remove the outer designer tag and presentation background. Do not invent project locations, work completed or a working carousel from the static counter.
```

## Uygulama ve sınır

İkinci süreç satırının vurgusu görünüyor; tab, accordion veya hover davranışından hangisi olduğu doğrulanmadı. Kaynak bir süreç bölümü için güçlü görsel referans, eksiksiz canlı site veya mobil kanıtı değil.
